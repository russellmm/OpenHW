## Decisions to keep

- **Standalone.** OpenHW must never reference openfan-linux (`/mnt/SOLIDIGM/ChatGPT/openfan-linux`), at build or
  run time — the owner changes that project and it must not break OpenHW. Read paths were copied and trimmed;
  write paths were left out. Port future features by copying, not referencing.
- **Engines per sensor suite** (owner's preference). Each engine discovers and reads on its own and honours a
  "requested ids" set so collapsed groups cost nothing.
- **Read-only today; writes later through the helper** (GPU/CPU power limits, CPU max frequency — see ROADMAP).
  Every helper command must be fixed and validated; nothing a client sends becomes a path, register or opcode.
- **Headless testing first** (owner's preference): `dotnet test`, `--dump` diffs, headless Skia renders. GUI
  screenshots (`import -window <xid>`) only for visual changes. Don't inject input into the desktop.
- **Gray means stale.** A row is drawn gray while its values are frozen; there is no instant poll on expand, so
  the gray is visible until the next regular poll.

## Gotchas learned the hard way

- **`Tmds.DBus.Protocol` `MessageWriter` is a `ref struct`.** Helpers must take it `by ref`; passing by value
  silently drops writes and the bus disconnects the app for a malformed reply.
- **Avalonia 11.2.3 pins Tmds.DBus.Protocol 0.20.0** (NuGet flags an advisory, NU1903). Upgrade them together.
- **Lingering is enabled for `russellm`**, so new group membership needs a **reboot**, not a relogin (the user
  systemd manager keeps boot-time groups). Use `sg openhw -c '…'` to test group access before a reboot.
- **NTFS mount**: git `core.filemode` is false — set exec bits with `git update-index --chmod=+x`. Files are
  created 777; `systemd-analyze verify` warns about that on the unit (install copies it 644).
- **Expensive reads**: NVML PCIe throughput (~42 ms/GPU, now every 10 s) and NVMe hwmon temperatures (5–19 ms per
  drive, each an admin command that can wake the drive). Everything else is < 2 ms per poll.
- **Rate sensors** (CPU usage, C-states, network/NVMe rates) need two samples after a pause; `PauseTracker` keeps
  them frozen until they produce a value.
- **Headless window captures don't include popups** (tooltips); test tooltip content, not pixels.
- `/mnt/SOLIDIGM/CLAUDE.md` describes a website-recreation workflow (Tailwind, PowerShell, Windows paths) — it
  doesn't apply to this project.
